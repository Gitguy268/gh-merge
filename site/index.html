gh merge
Use AI agents GitHub

Merge all your open pull requests with one command.

gh merge is an extension for the GitHub CLI. It lists the open pull requests in a repo, or in every repo you own, shows you the plan, and merges whatever GitHub can merge. Drafts and conflicts are skipped. CI status is ignored.

gh extension install Gitguy268/gh-merge

Use

# what would happen in the repo in this folder
gh merge --dry-run

# show the list, ask, then merge
gh merge

# every repo you own, only Dependabot, and ask it to rebase conflicts
gh merge --all --author app/dependabot --rebase-dependabot

# can't merge yet? turn on auto-merge instead
gh merge --auto

What it does

One repo or all of them

The repo you're in, -R owner/name, every repo you own with --all, or an org with --owner. Archived repos are skipped.

One at a time

After each merge it checks the next pull request again, because merging one often puts the next into conflict.

Your repo's rules

It uses the merge method your repo allows, unless you pick one. Branch protection still applies, and --auto turns on auto-merge instead.

With or without an AI coding agent

Run it yourself, or let Claude Code, Codex, opencode or another agent run it. When there's no terminal it never asks a question: without --yes it prints the plan and exits with code 2. --json gives a result for every pull request.

# teach your agents the tool (Claude Code, Codex, opencode, ~/.agents)
gh merge install-skill

# what the skill tells them: preview, ask you, then merge
gh merge --all --dry-run --json
gh merge --all --yes --json
0done, or nothing to do
1error
2nothing merged: not confirmed
3some pull requests were skipped or failed (drafts don't count)
